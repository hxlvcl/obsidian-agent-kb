# 错误日志

> 记录知识库操作中的验证失败、流程中断、异常事件。
> 按日期分组，最新日期排在最前面。每条记录和管理日志格式一致。

## 格式说明

每条记录按以下 markdown 格式（日期由分组标题 `## YYYY-MM-DD` 定义，每条记录不重复写时间）：

```markdown
### 错误类型名

**操作**：入库 / 编译Wiki / 移动文件 / ...
**文件**：影响到的文件路径
**原因**：失败的具体原因
**状态**：未解决 / 已解决 / 待确认
**规则改进**：（若有则写，否则留空）
```

## 2026-04-27

### 双链乱建：无关概念强行互链

**操作**：Wiki 概念页编译
**文件**：02-Wiki/04-社会/性别红利.md、02-Wiki/04-社会/政府继承与条约审查.md
**原因**：以"同一类别（04-社会）的不同议题"为由，给完全不相关的概念建立双链。同分类 ≠ 该互链。
