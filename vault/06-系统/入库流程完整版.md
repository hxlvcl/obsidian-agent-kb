# 知识库管理员 — 入库流程完整版 v4.2

> **三阶段**：整理入库（留在收件箱）→ 编译 Wiki（不管链）→ 脚本建链 → 移动归档

---

## 前置条件

1. 读取 `知识库管理指南.md` 和 `AGENTS.md`
2. `python scripts/git_control.py pre "入库整理"`
3. 读取 `06-系统/模板/新笔记.md` 和 `Wiki概念页.md`

---

## 阶段一：整理入库

### 第1步：扫描收件箱
列出 `00-收件箱/` 下所有笔记。

### 第2步：阅读内容
read_file 读正文，不凭标题猜。

### 第3步：提出分类建议
列出：文件名 → 建议分类。不含链接建议。

### 第4步：用户确认后操作

#### 4a. 修改 frontmatter
按模板格式填充。

#### 4b. 清理残留
移除：`^作者[:：]`、`^时间[:：]`、`^来源[:：]`、`^\d+ 人赞同`、正文残留 `相关:`、多余 frontmatter。

#### 4c. 正文末尾占位
```
**关联文章**

（待统一建链）
```

### 第5步：自检
对照模板 → 不通过则 rollback + 错误日志 + 终止。

### 第6步：暂留收件箱
文件留在 `00-收件箱/`，等待阶段三建链。Git 提交标注 `"入库整理（待建链）"`。

---

## 阶段二：编译 Wiki

### 第8步：扫描匹配
遍历 `02-Wiki/`，判断每篇新文章匹配哪个概念页。

### 第9步：提 Wiki 变更方案
表格列出，等用户审核：

| 文章 | 操作 | 目标 |
|------|------|------|
| 文章A | 增量更新 | `02-Wiki/01-科技/Skill生态.md` |
| 文章B | 新建概念页 | `02-Wiki/03-哲学/xxx.md` |
| 文章C | 仅索引 | `_index.md` 01-科技 |

### 第10步：用户审核
审一次，确认或修改。

### 第11步：新建概念页
用 Wiki 模板创建，包含 `**关联文章**` 空区块（填充留待阶段三）。

**新建后必须追加到 `_index.md`**：
```bash
python scripts/safe_link_appender.py --wiki-index --category "01-科技" --entry "[[概念名]] — 摘要"
```

### 第12步：增量更新
正文末尾追加 `### 补充观点`，不覆盖原内容。

### 第13步：仅索引
```bash
python scripts/safe_link_appender.py --wiki-index --category "01-科技" --entry "[[文章]] — 摘要"
```

**不涉及任何链接操作。**

### 第14步：Git 提交
`python scripts/git_control.py post "编译Wiki：N篇 → {概念页}"`

---

## 阶段三：脚本建链 + 移动归档

### 第15步：扫描全库 + 自动补回链
读取本次入库文章 + Wiki 概念页 + 已有文章。

**先跑** `python scripts/supplement_linker.py`：
- 扫描所有 Wiki 页的 `#### 来自《文章名》` 补充观点
- 全库前缀匹配解析完整文件名
- 在标题下一行插入 `- [[完整文件名]]`
- 插完后验证：每条链接必须精确命中 `.md` 文件，未命中的标出

### 第16步：提关联方案
按表格输出，**每行一个关联关系**：

| 文章 | 关联文章 | 理由 |
|------|---------|------|
| A | B | 同主题 |
| A | C | 同作者 |
| B | D | 引用观点 |

判断逻辑：同主题、同作者、同概念、语义关联。脚本自动累积去重。

### 第17步：用户审核
审一次，确认或修改。

### 第18步：脚本建链
逐行构造命令，同一篇文章多次调用自动累积：
```bash
python scripts/safe_link_appender.py --new-article --target "00-收件箱/A.md" --links "B"
python scripts/safe_link_appender.py --wiki-concept --target "02-Wiki/01-科技/xx.md" --article "A"
python scripts/safe_link_appender.py --wiki-index --category "01-科技" --entry "[[A]] — 摘要"
```
⚠️ `--links` 必须传文件名的**真实开头**（`dir /b` 查证），禁止 AI 脑补缩写。前缀匹配仅一层兜底，传错开头=悬空。
⚠️ `--new-article` 自动拦截 Wiki 概念页链接（`_is_wiki_concept()`）。

### 第19步：移动归档
从 `00-收件箱/` 移到 `01-素材库/` 对应分类

### 第20步：Git 提交 + 管理日志
`python scripts/git_control.py post "统一建链：N篇，X条链接"`
管理日志附链接方案表格。

---

## 回滚方法
- 恢复单个文件：`python scripts/git_control.py restore "路径"`
- 回滚到上一版本：`python scripts/git_control.py rollback`

## 修改原则
- 只改用户指出的文件
- 不主动检查/修改其他文件
