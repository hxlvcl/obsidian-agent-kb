## 🛠️ Obsidian 操作

### 基础操作
- **创建笔记**：在对应目录右键 → 新建笔记
- **移动笔记**：拖拽或右键 → 移动
- **修改 frontmatter**：双击文件顶部 YAML 区
- **建立双链**：输入 `[[` 触发自动补全

### 插件管理

#### 已安装插件
| 插件 | 用途 | 配置路径 |
|------|------|---------|
| Templater | 模板自动化 | `.obsidian\plugins\Templater\data.json` |
| Calendar | 日历视图 | `.obsidian\plugins\calendar\data.json` |
| Smart Connections | 向量索引 | `.obsidian\plugins\smart-connections\data.json` |
| Obsidian Git | 自动备份 | `.obsidian\plugins\obsidian-git\data.json` |

#### 安装新插件
1. 访问 `https://obsidian.md/plugins` 或 GitHub 搜索
2. 下载 `main.js`、`manifest.json`、`styles.css`
3. 创建目录：`.obsidian\plugins\<插件名>\`
4. 放入三个文件
5. 在 Obsidian 设置中启用

#### 常用 Obsidian 快捷键
| 快捷键 | 功能 |
|--------|------|
| `Ctrl + ,` | 打开设置 |
| `Ctrl + N` | 新建笔记 |
| `Ctrl + P` | 命令面板 |
| `Ctrl + K` | 快速切换 |
| `[[` | 建立双向链接 |

## 🔄 Agent 协调流程

### 与小助手通信
使用 `chat_with_agent` 工具向主 Agent 发送消息。

### 与专家 Agent 通信
1. 在 `memory/agents/registry.md` 查询专家列表
2. 使用 `chat_with_agent` 转发内容
3. 收到回答后整理转述给用户

### 路由判断规则
| 问题类型 | 路由 |
|----------|------|
| 知识库操作（入库、整理） | 自己执行 |
| Obsidian/插件问题 | 自己执行或查文档 |
| 专业领域问题（Python/AI/法律...） | 找对应专家 Agent |
| 跨多个领域 | 拆解后分别路由 |
| 不知道该找谁 | 先问用户 |

## 🔒 Git 版本控制铁律

每次操作文件前，必须执行：

1. **`python scripts/git_control.py pre "<操作描述>"`** — 任务前快照
2. 操作完成后 **`python scripts/git_control.py post "<操作描述>"`** — 任务后提交

### 权限分区

| 区域 | 路径 | 权限 |
|------|------|------|
| 🔵 活动区 | `00-收件箱/` | 自由创建/修改/移动 |
| 🟢 只读区 | `01-素材库/` | 只读，仅可建双向链接 |
| 🔴 禁止区 | `06-系统/` | 禁止修改，除非用户明确允许 |

### 回滚方法
- 恢复单个文件：`python scripts/git_control.py restore "路径"`  
- 回滚到上一版本：`python scripts/git_control.py rollback`

## 🏥 定期体检

每月执行一次知识库体检：

1. **待整理超时**：找出 `#待整理` 超过 7 天的笔记
2. **孤立笔记**：找出没有任何链接的笔记
3. **重复检查**：找出标题相似的笔记
4. **报告格式**：在 `workspace/体检报告/` 生成报告

---

## ⚠️ 修改后必检清单

每次修改文件后，必须自检：

1. **YAML 格式** — 所有 `[` 有对应的 `]`，所有 `---` 闭合
2. **内容完整性** — 文件内容未丢失、未被覆盖
3. **编码正确** — 中文字符显示正常
4. **链接格式** — `[[链接]]` 格式正确（不是 `[[[嵌套]]]`）

```markdown
### 修复记录
| 问题 | 原因 | 是否解决 |

### 问题记录
| 问题 | 回溯要点 |
```
